## 💻 How to Use the Scripts

Choose the method that matches the type of script you want to run.

### 1. Lua Engine — One-Time Execution

1. Open **Cheat Engine**.
2. Press `Ctrl + Alt + L` to open the **Lua Engine** window.
3. Copy the code from the required `.lua` file in this repository.
4. Paste the code into the Lua Engine and click **Execute**.

### 2. Auto Assemble — One-Time Execution

1. Open **Cheat Engine**.
2. Press `Ctrl + Alt + A` to open the **Auto Assemble** window.
3. Copy the code from the required Auto Assemble script in this repository.
4. Paste it into the Auto Assemble window and click **Execute**.

### 3. Autorun — Load Automatically on Startup

1. Download the required `.lua` script from this repository.
2. Move or paste the script into Cheat Engine's **`autorun\custom`** folder. The usual location is:

   ```text
   C:\Program Files\Cheat Engine\autorun\custom
   ```

3. Restart Cheat Engine. The script should now load automatically whenever Cheat Engine starts.
